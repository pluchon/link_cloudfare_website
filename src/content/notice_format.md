# 公告标题

> 一句话简介（页面上不显示，只作为页面描述）

***

![封面，可以不写](OSS链接，任何格式都支持)

***

> tags: [公告类型, 其他标签]

> date: 2026-11-02 12:00

开头可以直接写正文。`tags` 的第一个是公告类型，显示在左侧列表的最右边；想置顶就在 `tags` 里加一个「置顶」，比如 `[置顶, 站务]`。`date` 建议带上时分，顶栏小铃铛的红点和 NEW 都按它算，发布 24 小时后消失。

## 二级标题

一级、二级标题会进右侧索引。

```xiaomeng
小萌说的话，显示成一个粉色的框。

空一行就是下一段。
```

## 引用站内文章

写文章的地址，分类、时间、封面、标题、简介和标签都会自动取。地址写错会让构建失败。

```post
/project/文章的地址/
```

## 引用站外链接

`title` 和 `url` 必填，`url` 要以 https 开头，`desc` 和 `cover` 可以不写。

```link
title: 链接标题
desc: 一句话介绍
url: https://github.com/你的名字/仓库名
cover: OSS链接
```
