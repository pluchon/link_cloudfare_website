大多数个人站看起来乱，不是因为元素太丑，而是因为**分隔手段太多**：卡片、阴影、圆角、色块、渐变，五种东西同时在划分区域，眼睛就不知道该跟着哪条线走。

这个站只保留一种：**1px 的发丝线**。

## 三条规则

1. 分区只用线，不用色块
2. 强调色（朱红 `#C6462F`）只出现在交互反馈上，不做大面积填充
3. 标题用宋体、正文用黑体、元信息用等宽 — 靠字体族区分层级，不靠字号堆叠

第 3 条是重点。中文站最容易犯的错是所有文字都用同一款黑体，然后靠 18px / 16px / 14px 来分层，结果层级全糊在一起。换成宋体做标题，一眼就能分开。

## 代码块也一样

代码块没有背景色差、没有圆角，只有一圈线：

```ts
// 只用变量，不写死颜色，深浅色自动跟着切
const line = 'var(--line)';
const accent = 'var(--accent)';
```

悬停时右上角才浮出 COPY 按钮，静止状态下版面是干净的。

## 关于字体

没有加载任何中文 Web 字体。原因很直接：

| 方案 | 首屏 | 代价 |
|------|------|------|
| 加载思源宋体全量 | 慢 | 单个字重 8MB+ |
| 子集化后加载 | 中 | 生僻字会掉字 |
| 系统字体栈 | 快 | 各平台略有差异 |

选了第三种。Windows 上是宋体 + 微软雅黑，macOS 上是宋体 + 苹方，都能撑住这套排版，而且**零外部请求**。

> 差异不是问题，抖动才是。

## 写在最后

线条这种东西，加一根很容易，删一根很难。这套样式的每一条线，都得回答一个问题：拿掉它，读者会不会看不懂结构？答不上来的，就删掉。
