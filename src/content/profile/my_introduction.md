# 关于我

> tags: [Java, Spring Boot, MyBatis-Plus, MySQL, Redis, Vue 3, Docker, AI Coding, Spring cloud Gateway, Nacos, Sentinel, Seata, Skywalking, Stitch, Codex, Claudecode]

现在在做全栈，后端多一些，前端也自己上。平时用 AI 工具干活，也用它写这个站。

这里就是我的笔记本。项目里踩过的坑、调了半天才找到原因的 bug、看到觉得值得记一笔的东西，都往这儿放。写久了发现，值得写下来的往往不是「怎么做」，而是「当时为什么会想错」。怎么做的教程到处都有，后面这部分基本没人写。

## 现在在做什么

- 一个人从数据库写到页面：后端 Spring Boot + MyBatis-Plus，前端 Vue 3
- 在拆微服务，顺便补自己的工程短板
- AI Coding：让它干活，也记下它干砸的地方

## 这里有什么

- **项目** — 做过的项目，和过程里的笔记
- **工具** — 用过的工具怎么用，教程和清单
- **探究** — 自己瞎想的东西，或者阶段性的研究结果
- **日常** — 和代码无关的生活碎片
- **小萌** — 一些资料和设计构想

## 关于这个站

纯静态，没有登录、没有数据库，也没有评论区。所有内容就是仓库里的 Markdown，推一次代码更新一次。

首页那张会自己长出来的导图是手写的，不是模板。全站只用 1px 的线做分隔，不加阴影、圆角和色块。我想看看光靠线条和留白能做到什么程度。
