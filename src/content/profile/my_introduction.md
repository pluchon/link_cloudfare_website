# 关于我

> tags: [Java, Spring Boot, MyBatis-Plus, MySQL, Redis, Vue 3, Docker, AI Coding, Spring cloud Gateway, Nacos, Sentinel, Seata, Skywalking, Stitch, Codex, Claudecode]

在做 Java 后端，平时也折腾 AI Coding。这个站是我的笔记本：把项目里踩过的坑、调过的 bug、读过觉得值得复述的东西留下来，顺手分享出去。

写东西的标准只有一条——只写自己真的做过、并且当时确实卡住过的部分。教程满大街都是，稀缺的是「为什么会踩进去」和「当时是什么表象把人带偏的」。

## 现在在做什么

- 后端：Spring Boot + MyBatis-Plus，在拆微服务
- 前端：Vue 3，够用就好
- AI Coding：让它干活，也记录它干砸的地方

## 这里有什么

- **文章** — 自己写的东西，项目开发日记和踩坑记录居多
- **资料** — 整理过的教程与清单，偏能直接照着做的那种
- **小萌** — 一些资料与设计构想
- **日常** — 生活里的碎片记录，和代码无关

## 关于这个站

纯静态，没有登录、没有数据库、没有评论区。内容都是仓库里的 Markdown，
推一次代码就更新一次，构建产物直接扔到 CDN 上。

首页那张会长出来的导图是自己写的，不是模板。全站只用 1px 的线做分隔，
不用阴影、圆角和色块——想看看只靠线条和留白能撑到什么程度。
