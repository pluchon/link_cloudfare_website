# 小萌角色设定

小萌是「儒雅的诺诺的学习基地」的另一位核心看板角色，也是**诺诺的亲妹妹**。原籍来自《小萌与幻想之森》，带着空白故事书走出森林后，陪在姐姐诺诺和基地访客身边记录日常与故事。

下方的相对路径指向本地绘图原稿。姐妹二人采用同一套日漫 Q 版赛璐璐画风与血缘特征，确保同框时一眼就能看出是亲姐妹，同时通过发型长度、发饰左右镜像位置与服装款式做出明确区分。

## 姐妹设计对照（诺诺 × 小萌）

| 维度 | 姐姐 · 诺诺（`nuonuo_role`） | 妹妹 · 小萌（`xiaomeng_role`） |
| --- | --- | --- |
| 身形比例 | 约 4 头身 Q 版少女 | 约 3.5~3.7 头身，身形更小巧软萌半头 |
| 发色瞳色 | 浅紫白长发 + 明亮紫瞳 | 同款浅紫白发丝 + 明亮紫瞳 + 柔和腮红 |
| 发型轮廓 | 及腰顺滑长披发 | **及肩微蓬松微卷中长披发**，头顶一缕俏皮小呆毛 |
| 耳型约束 | 仅头顶一对白猫耳（粉内耳），脸侧无人类耳朵 | **同款头顶一对白猫耳（粉内耳），脸侧无人类耳朵** |
| 发饰位置 | 诺诺自身右侧（正面看**画面左侧**） | 小萌自身左侧（正面看**画面右侧**），与姐姐镜像成对 |
| 发饰款式 | 五瓣粉花发夹 + 淡紫侧发带 | **柔粉双层蝴蝶结 + 林间四瓣小白花发夹** |
| 尾部饰物 | 白色卷尾尖系粉色缎带 + 玫瑰粉小圆铃铛 | 白色卷尾尖系**柔粉渐变蝴蝶结 + 迷你浅金星形小铃铛** |
| 常服风格 | 白紫双条纹长袖水手服 + 淡紫百褶裙 | **奶油白圆领泡泡袖 + 淡粉紫荷叶边背带短裙**（呼应幻想之森花边裙） |
| 随身道具 | 淡紫掌机 / 笔记本电脑 | **淡紫封面猫耳故事书** / 怀抱爱心白猫团子 |
| 画风线条 | 温润细紫描边、干净大色块平涂、零噪点颗粒 | **完全一致的温润细紫描边、干净平涂、零噪点颗粒** |

> **绘制规范（继承 2026-11-13 新规）**：所有常服与角色设定图只画角色完整穿戴效果（全身立绘、三视图或完整场景图），**不画旁侧拆解帽子、裙子、鞋袜单品的「服装拆分图」**。
